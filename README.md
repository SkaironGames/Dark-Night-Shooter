# Dark Night Shooter

## About
Dark Night Shooter is a Unity FPS Zombie Survival game developed by Nikhil Sonar.

## Features
- FPS Shooting
- Zombie AI
- Boss Fight
- Health System
- Ammo System
- Wave Survival
- C# Scripts
